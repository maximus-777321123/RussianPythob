# Russian — пиши игры на Python по-русски с нейросетью и магией

**Russian** — это библиотека для Python, которая позволяет писать игровые проекты на русском языке, с использованием нейросетей, генерацией текстур и встроенным игровым движком. Идеально подойдёт для начинающих и любителей, которые хотят писать игры понятно, красиво и просто.

## Возможности

- `Russian.language("True")` — активирует русский синтаксис
- `игра.запустить()` — запуск игрового окна на базе Ursina
- `игра.сохранить("имя")` / `игра.загрузить("имя")` — сохранение и загрузка игры
- `игра.нарисовать.текстуру("описание")` — генерация текстур с помощью g4f + PIL
- `gpt.input` — автоматическое считывание текста из чата игрока
- `gpt.game(описание, запрос)` — создание сущности с интеллектом и характером
- `Gpt.response.chat(...)` / `Gpt.response.up(...)` — вывод ответа в чат или над объектом
- `help.alian()` — справка по всем командам
- `war.on()` — боевой режим
- Интеграция с движком **Ursina**
- Стартовая игра — в файле `пример_игры.py`

## Установка

```bash
pip install ursina pillow g4f
```

## Пример

```python
from russian import Russian, игра, gpt, Gpt

Russian.language("True")
игра.запустить()

игра.нарисовать.текстуру("каменный куб с мхом")
герой = игра.Объект(модель="cube", текстура="textures/каменный куб.png")
игра.добавить(герой)

gpt.input = игрок.ввод
существо = gpt.game("Куб, мудрый, ворчит", gpt.input)
Gpt.response.chat(существо)
```
